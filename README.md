# TravelPulse

TravelPulse is a Streamlit dashboard for exploring destination weather, country information, currency, and local time through public APIs.

## Development status

The project is being built in staged commits. See the Git history for the progression from scaffold to complete dashboard.

## Quick start

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
streamlit run app.py
```
